# Chandru LG Portfolio

A static portfolio site built with HTML, CSS, and vanilla JavaScript. No package installation or build step is needed.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. Keep the image files beside `index.html` so the portrait, internship photos, gallery, and certificates load.

## Personal details

Edit `index.html` to update the biography, projects, education, experience, links, and contact address. Design tokens and responsive layouts live in `style.css`; menu, motion preference, credential slider, and email-draft behavior live in `app.js`.

The contact form opens a prefilled email draft to `lingamchandru53@gmail.com`; it does not deliver messages through a server.
